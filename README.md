# Portfolio — Bilal El Mouden

## Ouvrir sur votre ordinateur
Décompressez le ZIP, puis double-cliquez sur index.html. Aucun outil à installer.
Gardez le dossier assets à côté de index.html : il contient la photo et les deux CV.

## Publier sur GitHub Pages
1. Créez un dépôt GitHub, par exemple portfolio-bilal.
2. Ajoutez index.html, le dossier assets, .nojekyll et ce README à la racine du dépôt.
3. Dans Settings > Pages, choisissez Deploy from a branch, puis main et / (root).
4. Enregistrez et attendez que GitHub affiche le lien du site.
Le site et les documents seront accessibles publiquement si vous activez une publication publique.

## Modifier le site
Les textes, styles et interactions se trouvent dans index.html.
Les fichiers PDF sont dans assets. Conservez leurs noms pour garder les liens fonctionnels.
